# Chapter 1 Lab: Windows Editions, Features, and Core Administrative Tools

**Estimated time:** 20 minutes

## Exercise

Open Computer Management MMC, create a new local user in Local Users and Groups, then use Disk Management to shrink a partition and create a new simple volume

## Key takeaway

Know exactly which Windows edition unlocks which feature, and which administrative tool (Control Panel, Settings, or a specific MMC snap-in) performs which task.
