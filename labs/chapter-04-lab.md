# Chapter 4 Lab: Security Measures, Wireless Protocols, and Authentication

**Estimated time:** 20 minutes

## Exercise

Configure a SOHO wireless router: change the default admin password, set the SSID, enable WPA3 (or WPA2-AES if WPA3 unavailable), disable WPS, and enable MAC filtering

## Key takeaway

Default to WPA3 for wireless security, know AES as the cipher, and distinguish RADIUS from TACACS+ by what they encrypt and how they separate AAA functions.
