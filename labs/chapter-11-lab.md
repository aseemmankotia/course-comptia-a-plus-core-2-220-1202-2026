# Chapter 11 Lab: Incident Response, Regulated Data, Licensing, and Scripting Risks

**Estimated time:** 20 minutes

## Exercise

Write and safely test a simple PowerShell (.ps1) script that lists installed software, then review the PowerShell execution policy settings and explain the security risk of running unsigned scripts

## Key takeaway

Know which regulated data category applies based on the type of data and origin, not the company's location, and always document chain of custody in incident response.
