# Chapter 3 Lab: Installing Windows, Client Networking, and macOS/Linux Basics

**Estimated time:** 25 minutes

## Exercise

Configure a static IP on a Windows client, create and share a network folder with permissions, then join the same test VM to a workgroup and verify with net view

## Key takeaway

Choose the correct file system, partition style, boot method, and network model based on the specific requirements described in the scenario, not general preference.
