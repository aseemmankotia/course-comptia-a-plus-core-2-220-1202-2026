# Chapter 7 Lab: Troubleshooting Windows Boot, Performance, and Application Issues

**Estimated time:** 20 minutes

## Exercise

Boot a test VM into Windows Recovery Environment (WinRE), run Startup Repair, then boot into Safe Mode and use Event Viewer to identify the service causing a boot delay

## Key takeaway

Trace Windows symptoms back to their most recent trigger (update, driver, profile corruption) before jumping to drastic fixes like reinstalling the OS.
