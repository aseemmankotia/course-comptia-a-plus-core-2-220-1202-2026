# Chapter 2 Lab: Windows Command-Line Utilities for Diagnostics and Networking

**Estimated time:** 25 minutes

## Exercise

Open an elevated Command Prompt, run ipconfig /all, ping a remote host, run sfc /scannow, then use net use to map a network drive and robocopy to mirror a folder

## Key takeaway

Match each command-line utility to its specific diagnostic purpose - the exam tests precise command syntax and correct use case, not general familiarity.
