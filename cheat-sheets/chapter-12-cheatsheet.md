# Chapter 12 Cheat Sheet: Full Exam Simulation & Strategy

## Exam Format Basics
| Item | Value |
|---|---|
| Max questions | 90 |
| Total time | 90 minutes |
| Passing score | 700 |
| Score scale | 100–900 |
| Avg. time/question (MC) | ~60 sec |

## Test Center vs Online-Proctored
| Factor | Test Center | Online-Proctored |
|---|---|---|
| Room scan | Not needed (controlled room) | Required (360° webcam scan) |
| Desk clearance | Provided by center | Must clear desk yourself |
| ID verification | In person | Via webcam |
| Notes/scratch paper | Provided on-site, collected after | None allowed; no personal materials |
| Second monitor | N/A | Prohibited |

## PBQ Strategy
- PBQ types: **drag-and-drop** (ordering/matching) and **simulation** (mock interface/terminal interaction).
- PBQs typically appear **early** in the exam.
- Budget a **larger time block upfront** (e.g., first 10–15 min) for PBQs — don't let them eat into your per-question MC average.
- PBQs are **not weighted more** than multiple-choice questions — don't over-invest time on one.
- If stuck: submit best attempt → flag → move on.

## Multiple-Response Identification
- Watch for explicit instruction text: "select two," "choose all that apply."
- Selecting the **wrong number** of options = entire question marked wrong (no partial credit).
- Default assumption for any question without such wording: **single answer only**.

## Time Budget Formula
```
Total time: 90 min
PBQ reserve: ~10-15 min upfront
Remaining MC time: ~75-80 min ÷ ~75-85 MC questions ≈ 60 sec/question
Review buffer: keep last 5 min for flagged question review
```

## Process-of-Elimination Workflow
1. Read scenario fully — note constraints/keywords.
2. Eliminate options clearly unrelated to symptoms/requirements.
3. Compare remaining plausible options against scenario details.
4. Choose best match; if still unsure — **flag and continue**.

## Flag-and-Review Rules
- Never leave a question blank (blank = automatically wrong).
- Flag uncertain questions with a best-guess answer already selected.
- Return to flagged questions only after finishing all questions once.
- Use remaining buffer time for final flagged review, not for re-second-guessing confident answers.

## Score Report
- Overall result: **Pass/Fail** based on scaled score vs. 700 threshold.
- Domain breakdown: shows **relative strength/weakness by objective** — not specific missed questions (exam questions are never disclosed).
- Use domain breakdown to prioritize retake study time on weakest domains.
